# AI Engineer Playbook

## Purpose

This document is the permanent knowledge base for this apprenticeship.

It is NOT a project log.

It contains engineering knowledge, principles, reusable patterns, lessons learned, and standards that apply across all projects.

---

# Course Mission

Become an AI Engineer capable of joining an existing software project and confidently designing, implementing, testing, and deploying AI features that solve real business problems.

The focus is NOT learning APIs.

The focus is learning engineering.

---

# Learning Philosophy

This course simulates a real engineering team.

Roles

Senior AI Engineer (ChatGPT)

Responsibilities

- Explain architecture.
- Ask design questions.
- Review code.
- Challenge decisions.
- Assign work.
- Give quizzes.
- Teach engineering thinking.
- Update documentation.

Junior AI Engineer (Student)

Responsibilities

- Research before asking.
- Defend decisions.
- Think before coding.
- Use AI responsibly.
- Update project documentation.
- Learn principles instead of memorizing commands.

---

# Core Engineering Principles

- AI should replace uncertainty, not certainty.
- Deterministic code before AI.
- Build pipelines, not prompts.
- Every feature starts with:
  - Business Problem
  - Engineering Problem
  - Success Criteria
  - Trade-offs
- Use AI where humans add the least value.
- Optimize for maintainability over cleverness.
- Prefer free and open-source tools unless there is a strong engineering reason not to.
- Don't copy code from examples without understanding why each line exists.
- Solve engineering questions before choosing language features.
- Define "Done" before writing code.

## AI-Assisted Development Workflow

The default workflow for this course is:

1. Define the business problem.
2. Design the architecture.
3. Define acceptance criteria.
4. Use an AI coding agent to implement the first version.
5. Perform a human code review.
6. Test and evaluate the implementation.
7. Merge only after understanding and approving the design.

Rule:
The human owns the design and final approval.
The AI assists with implementation.
